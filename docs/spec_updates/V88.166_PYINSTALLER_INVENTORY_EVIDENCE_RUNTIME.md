# V88.166 — evidência agregada no runtime do EXE (18/11/2026)

## Causa encontrada no aceite Tapajós

O build anterior compilou e passou as provas locais, GUI, imagem óptica e rotas SAR live, mas falhou no aceite do EXE em cópia limpa: pixels SAR estavam válidos e nenhum agregado elegível apareceu. O diagnóstico do runner mostra que `structural_aggregate_evidence_v1.csv` era copiado para a pasta externa `dist/Enform Verde/data`, enquanto `inventory_agb_comparison` consulta `data/` relativo ao runtime congelado em `_internal`. A tabela não estava empacotada no local que o módulo realmente lê.

## Correção

- O comando PyInstaller adiciona explicitamente `data/structural_aggregate_evidence_v1.csv` ao destino `data` do runtime interno.
- O gate Windows exige o arquivo em `_internal/data` e verifica a presença das referências Tapajós KM72 e KM117 antes do aceite.
- O relatório de aceite inclui estado, diagnóstico, contagem e fontes do registro de inventários. Uma falha de leitura aparece como `ERRO_TECNICO_LEITURA_REGISTRO_INVENTARIOS`, com JSON completo no log do runner.
- A ausência de modelo quantitativo segue AGB=N/D; médias publicadas permanecem referências comparativas separadas, sem virar estoque ou calibração.
