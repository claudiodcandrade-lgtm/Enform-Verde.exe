# V88.140 — ajustes da regressão de vigor (18/11/2026)

Versão candidata: `3.26.65-PRECAMPO-EXPERIMENTAL`.

- A primeira suíte completa após V88.139 executou 1.268 testes e encontrou quatro incompatibilidades nos testes, sem regressão sintática: o novo teste não importava `datetime`; dois testes simulavam ausência sem retorno das auditorias MPC/INPE; e um teste da máscara anual fazia busca live sem querer, encontrando uma cena real e tornando o resultado não determinístico.
- Ajustados os testes para representar evidência real e permanecer offline: ausência só com as duas fontes completas e sem cena; teste que verifica apenas o encaminhamento da máscara usa N/D explícito; a cena válida e probabilidades para o contrato de aplicação do vigor são fornecidas por fixture separado; o helper importa explicitamente o relógio UTC.
- Nenhum gate de produção foi relaxado. Esta revisão ainda precisa passar a regressão completa, o workflow Windows e o live SAR/IFN/previsão no SHA final; até lá, não declarar a build liberada.
