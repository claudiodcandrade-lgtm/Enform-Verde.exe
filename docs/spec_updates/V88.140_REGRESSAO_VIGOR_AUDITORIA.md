# V88.140 — ajustes da regressão de vigor (18/11/2026)

Versão candidata: `3.26.65-PRECAMPO-EXPERIMENTAL`.

- A primeira suíte completa após V88.139 executou 1.268 testes e encontrou quatro incompatibilidades nos testes, sem regressão sintática: o novo teste não importava `datetime`; dois testes simulavam ausência sem retorno das auditorias MPC/INPE; e um teste de integração com cena/probabilidades válidas esperava incorretamente N/D em vez de vigor experimental.
- Ajustados os testes para representar evidência real: ausência só com as duas fontes completas e sem cena; dados de vigor com cena/data e probabilidades válidas permanecem experimentais; teste do helper importa explicitamente o relógio UTC.
- Nenhum gate de produção foi relaxado. Esta revisão ainda precisa passar a regressão completa, o workflow Windows e o live SAR/IFN/previsão no SHA final; até lá, não declarar a build liberada.
