# V88.176 — mapa temático vetorial, testes e evidências do pacote (21/11/2026)

## Decisão de interface
O fundo óptico deixa de ser requisito operacional ou gate para disponibilização. O mapa local deve sobrepor à geometria vetorial as classes de uso/cobertura efetivamente produzidas, com legenda contendo classe, área, percentual e origem. A classificação SAR continua explicitamente experimental; mapa anual não deve ser apresentado como cobertura atual.

## Correção do gate de testes
A regressão não pode depender de um simulador de fundo óptico nem de janela Tk modal em execução sem operador. O teste de handoff substitui a renderização de mapa por stub quando seu escopo é apenas verificar o encaminhamento dos resultados ao dashboard. O contrato visual verifica o mapa temático local e não exige fundo óptico. Isso corrige uma falha do harness e evita congelamento da CI, sem alterar a lógica de cálculo do produto.
