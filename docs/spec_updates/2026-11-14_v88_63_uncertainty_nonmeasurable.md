# V88.63 — exibição de incerteza não mensurável

A arquitetura já exige reportar incerteza para cada estimativa de carbono. Quando o valor tiver suporte mas algum parâmetro não permitir mensurar a incerteza, manter o valor e exibir exatamente “incerteza não mensurável”, identificando parâmetro, motivo e fonte consultada. Reservar N/D para o próprio valor sem suporte. Aplicar no painel, relatório, mapas, planilhas e exportações.

A branch mantém descoberta de inventários publicados e fontes institucionais, priorizando compatibilidade de fitofisionomia/região e, entre estudos equivalentes, dados primários abertos de parcelas. Serrapilheira gravimétrica e IFN compatível permanecem no catálogo sem exclusividade. Este checkpoint não representa uma nova fonte ingerida ou validação científica.
