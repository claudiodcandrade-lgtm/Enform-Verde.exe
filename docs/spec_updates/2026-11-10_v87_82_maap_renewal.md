# V87.82 — ESA MAAP: renovação de token em 90 dias — 10/11/2026
## Requisito de operação Windows
- O ESA MAAP Long-Lasting Offline Token tem validade nominal de 90 dias (fonte oficial ESA MAAP Knowledge Base). A renovação é manual mediante autenticação do usuário no portal oficial https://portal.maap.eo.esa.int/ini/services/auth/token/ .
- A aba SAR do Enform Verde possui entrada protegida de token ESA MAAP (caracteres mascarados). O botão RENOVAR TOKEN NO PORTAL ESA abre a URL oficial. SUBSTITUIR TOKEN descarta o segredo anterior mantido em memória e posiciona o foco no campo para colagem do token novo. REGISTRAR DATA DE EMISSÃO / RENOVAÇÃO informa AAAA-MM-DD, data efetiva de geração do novo token.
- Nenhum token ou hash de token é armazenado em arquivo pelo lembrete. Somente data de emissão, versão de esquema e validade nominal são gravadas em ~/.enform_verde/esa_maap_token_renewal.json. O acesso aos dados ESA usa o token só no fluxo de autenticação quando necessário, mantendo consulta pública sem credenciais quando possível.
- O estado é UNKNOWN sem data, VALID_ESTIMATED quando restam mais de 15 dias, EXPIRING_SOON de 15 a 1 dias, EXPIRED no dia 90 ou depois. Exibir mensagem e oferecer abertura do portal no início do programa se estiver EXPIRING_SOON ou EXPIRED.
- A data informada é declaratória e não prova autenticação aceita nem garante que a ESA já não tenha revogado um token. Não registrar log de token nem URL com segredo. Tratar erro técnico, token inválido e ausência de cena como causas distintas.
- O novo módulo esa_maap_token_renewal.py e os testes tests/test_esa_maap_token_renewal.py integram a versão experimental 3.26.11. A CI Windows deve confirmar empacotamento e teste do mesmo código, sem confundir passagem dos testes de GUI com homologação científica nacional.
